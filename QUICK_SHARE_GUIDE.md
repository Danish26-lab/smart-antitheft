# 📤 Quick Guide: Share Agent with Friend

## Super Simple 3-Step Process

### Step 1: Create ZIP Package
1. Go to `device_agent` folder
2. **Double-click `CREATE_DISTRIBUTION.bat`**
3. Wait for ZIP file to be created (`antitheft-agent-installer.zip`)

### Step 2: Upload to Google Drive
1. Go to https://drive.google.com
2. Click "New" → "File upload"
3. Upload `antitheft-agent-installer.zip`
4. Right-click file → "Share" → "Get link"
5. Set to "Anyone with the link can view"
6. **Copy the link**

### Step 3: Send to Friend
Send this message to your friend:

```
Hi! To install the anti-theft agent:

1. Download from: [PASTE_YOUR_GOOGLE_DRIVE_LINK_HERE]
2. Extract the ZIP file
3. Open device_agent folder
4. Double-click INSTALL.bat
5. Wait 2-3 minutes
6. Done! Agent is running automatically.

No configuration needed - everything is automatic!
```

## That's It! 🎉

Your friend can now download and install the agent remotely!
