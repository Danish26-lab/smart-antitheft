# 🚀 Quick Setup Guide for Friend's Laptop (Prey-Style)

## The Problem
Your friend's device shows "Unknown location" and buttons don't work because the **device agent is not installed**.

## ✅ Super Simple Solution (Like Prey Project)

### Just 2 Steps!

**Step 1:** Copy the `device_agent` folder to friend's laptop

**Step 2:** Double-click `INSTALL.bat`

**That's it!** Everything else is automatic - no configuration needed!

## What the Installer Does Automatically

✅ Checks Python (prompts if missing)  
✅ Installs all dependencies  
✅ Creates configuration  
✅ Sets up auto-start  
✅ Starts the agent  
✅ Registers device automatically  

## After Installation

1. Friend logs in to: `https://frontend-wine-iota-46.vercel.app`
2. Device automatically appears and links
3. Wait 1-2 minutes for first location update

## ✅ Done!

Now the device should show:
- ✅ Map with location
- ✅ Working Lock/Alarm/Wipe buttons
- ✅ Real-time updates
- ✅ Auto-starts on every login

## 🔄 Auto-Start

The installer automatically sets up the agent to start on every login - **no manual action needed!**

## ❓ Troubleshooting

**No location?** Wait 1-2 minutes, agent reports every 15 seconds

**Still not working?** Check `agent.log` file for errors

**Can't connect?** Check internet connection and firewall settings

**Python not found?** Installer will prompt - just follow the instructions
