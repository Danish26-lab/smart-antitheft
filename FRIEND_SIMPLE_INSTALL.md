# 🚀 Simple Installation for Friend (Prey-Style)

## The Problem
Your friend's device shows "Unknown location" because the device agent is not installed.

## ✅ Solution: One-Click Install (Like Prey Project)

### What Your Friend Needs to Do:

1. **Copy the `device_agent` folder** to their laptop
   - Via USB, Google Drive, or any method

2. **Double-click `INSTALL.bat`**
   - That's it! Everything else is automatic

3. **Wait 2-3 minutes** for installation to complete

4. **Done!** Agent is now running and will auto-start on every login

## What Happens Automatically (No Configuration Needed!)

✅ **Python Check** - Verifies Python is installed (prompts if missing)  
✅ **Dependencies** - Installs all required packages automatically  
✅ **Configuration** - Creates config file automatically  
✅ **Auto-Start** - Sets up Windows to start agent on login  
✅ **Agent Start** - Starts the agent immediately  
✅ **Device Registration** - Agent auto-registers device (no user input)  

## After Installation

1. Friend opens: `https://frontend-wine-iota-46.vercel.app`
2. Friend signs up or logs in
3. Device automatically appears in dashboard
4. Device automatically links to friend's account
5. Location updates start within 1-2 minutes

## If Python is Not Installed

The installer will prompt your friend:
1. Click "Y" to open Python download page
2. Download and install Python
3. **Important**: Check "Add Python to PATH" during installation
4. Run `INSTALL.bat` again

## Troubleshooting

**Agent not running?**
- Check Task Manager for `python.exe` or `pythonw.exe`
- Check `agent.log` file for errors

**Still not working?**
- Make sure Python is installed correctly
- Check internet connection
- Try running `python agent.py` manually
